## Release Date 11/26/2026

This is the first release of **Senri**. It is an ultra-fast variant caller for short-read DNA sequencing: SNVs, MNVs, indels, complex and
structural variants in single samples and tumour/normal pairs. It is built and validated for
hybrid-capture, paired-end targeted sequencing. Its core is a rewrite of the robust and versatile **[VarDictJava v1.8.3](https://github.com/AstraZeneca-NGS/VarDictJava)**
variant caller which is not actively maintained. The rewrite was focused on performance improvement, minimal external dependencies for easy deployment (no Java, R or Perl needed). Additional work is underway to extend the variant calling features, such as ITD and large deletion detection, improving signal to noise ratio, and UMI-aware variant calling. Future plans include adding the capability for variant calling on long-read sequencing data. Variant calling on amplicon data has not been included in this release. The app builds into one static binary that can be run on any linux system. MacOS systems will require a compilation for the target architecture (AMD64 or ARM64/AppleSilicon).

## Highlights

- At least the same performance characteristics in variant calling as **version 1.8.3 of VarDictJava**.
- **Truth-set recall.** On the [OncoSpan](https://horizondiscovery.com/en/reference-standards/products/oncospan-gdna) reference material, Senri finds all 187 known variants (ROI corresponding to the [CinCSeq](https://www.cincinnatichildrens.org/clinical-labs/our-labs/pathology/molecular-genomic-pathology-services/-/media/C99B1C995FC8428DA7080059BBF3AD70.ashx) NGS panel; scored
  with [aardvark](https://github.com/PacificBiosciences/aardvark)).
- **Faster.** On the Oncospan RM (1200x average coverage). Runtime is 44 s with 16 threads (`-th 16`), against 3m 16s for
  the Java version at identical thread count (not including the R and Perl steps, which add another 1-2 minutes to the runtime). Output does not depend on the
  thread count.
- **One file to install.** A fully static x86-64 Linux binary (glibc, built on Debian trixie)
  that needs no libraries or dependencies on the target machine.
- **VCF by default.** VCF 4.2 output with the upstream FILTER tags. FILTER annotation never
  removes records. `--tsv` writes the upstream table.
- **New: `-p` reports rejected variants.** It also writes candidates the caller rejected, with
  the first rule they failed as FILTER (`REJ_*`). The calls themselves don't change.

## Parity verification

Before the reference tooling was removed from the repository, the release code (commit
`9212c91`) was checked one last time against VarDictJava 1.8.3 (the released jar), its R
strand-bias scripts and its Perl VCF scripts:

| Check | Result |
|---|---|
| Test cases from the VarDictJava test suite (single sample and tumour/normal), at every caller stage (no realignment or SV calling; no SV calling; full) | 90/90 identical |
| VCF output against `teststrandbias.R` / `testsomatic.R` → `var2vcf_valid.pl` / `var2vcf_paired.pl`, including the somatic-only, clustering and threshold variants | 88/88 identical (the other 2 cases produce no VCF) |
| Command-line parsing; samples, regions, reference and reads per region | 335/335 and 97/97 identical |
| Oncospan panel (`-f 0.01`): table output and VCF | 8,850 rows and 8,568 records identical |
| Oncospan truth set (aardvark) | 187/187 variants recalled |

To repeat the checks, build commit `9212c91` and follow its `CONTRIBUTING.md` (needs Java 21,
R and Perl). Later versions diverge from VarDictJava on purpose.
